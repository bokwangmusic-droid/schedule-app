# 핏모두 (FITMODOO)

강사와 회원을 위한 피트니스 통합관리 앱입니다.

시간표, 회원관리, PT, 운동일지, 프로그램, 인바디, 체형분석 등 피트니스 운영과 운동 기록을 한곳에서 관리합니다.

## 기술 기준

- React Native
- Expo SDK 57
- TypeScript
- Expo Router
- Android 우선
- Metro 개발 포트 8082

## 로컬 실행

```bash
npm install
npm run start
```

> Android 앱 ID와 인증 딥링크 scheme은 기존 호환성을 위해 현재 값을 유지합니다.
